# 遥控器使用说明 Manual of Remote

## 总览

|  名称  |   类型   |         用途         |
|:------:|:--------:|:--------------------:|
|   SA   | 两档拨杆 |  切换 SB、SC 的用途  |
|   SB   | 三档拨杆 |   推杆 / 上同步带    |
|   SC   | 三档拨杆 | 总线舵机 / 下同步带  |
|   SD   | 两档拨杆 |     **下档急停**     |
| 左摇杆 |   摇杆   | 左右旋转，上下无反应 |
| 右摇杆 |   摇杆   |     上下左右平移     |


## 机构控制（如果和实际不对应，请尽快修改本手册）

### SA下

|      |  SB  |    SC    |
|:----:|:----:|:--------:|
|      | 推杆 | 总线舵机 |
| 上档 |  出  |          |
| 中档 |  回  |          |
| 下档 |  停  |          |

### SA上

|      |    SB    |    SC    |
|:----:|:--------:|:--------:|
|      | 前同步带 | 后同步带 |
| 上档 |    上    |    上    |
| 中档 |    下    |    下    |
| 下档 |    停    |    停    |


## 备注

原代码框架中 SC 下三急停，现改为 SD 下档急停。
