# 遥控器使用说明 Manual of Remote

## 总览

|  名称  |   类型   |         用途         |
|:------:|:--------:|:--------------------:|
|   SA   | 两档拨杆 |  切换 SB、SC 的用途  |
|   SB   | 三档拨杆 |   推杆 / 上同步带    |
|   SC   | 三档拨杆 | 总线舵机 / 下同步带  |
|   SD   | 两档拨杆 |     **下档失能**     |
| 左摇杆 |   摇杆   | 左右旋转，上下无反应 |
| 右摇杆 |   摇杆   |     上下左右平移     |


## 机构控制（如果和实际不对应，请尽快修改本手册）

### SA下

|      |  SB  |    SC    |
|:----:|:----:|:--------:|
|      | 推杆 | 总线舵机 |
| 上档 |  出  |          |
| 中档 |  回  |          |
| 下档 |  停  |          |

### SA上

|      |    SB    |    SC    |
|:----:|:--------:|:--------:|
|      | 前同步带 | 后同步带 |
| 上档 |    上    |    上    |
| 中档 |    下    |    下    |
| 下档 |    停    |    停    |


## 特殊设置

若 SA 上 && SB 中 && SC 中 && **SD 下**（此时总线舵机已失能，可手动摆到基准位置），将两个摇杆在指定方向**保持 2 秒以上**即可进行设置：

|              | 左摇杆 | 右摇杆 |
|:------------:|:------:|:------:|
| bus_cali_180 |  左上  |  右上  |
| bus_cali_90  |  左下  |  右下  |

备注：
- 进入特殊设置模式后：蓝灯慢闪，蜂鸣器短响一声；SB/SC 必须保持中档。若没有该提示，说明开关档位未被识别。
- 推对摇杆方向的瞬间会再短响一声，保持 2 秒后执行设置。
- 再次设置前需先松开摇杆回中。
- 设置成功：蜂鸣器短响一声，蓝灯闪烁；失败：蜂鸣器低音短响，红灯闪烁。

对于总线舵机的两项：
- 将两个总线舵机当前位置认作指定度数，此后 `BusServoSetAngle()` 及三档预设位置均作修正。
- 两个总线舵机都必须正常回包，否则本次设置不生效。
- 设置成功后修正量写入 Flash，掉电保存。
