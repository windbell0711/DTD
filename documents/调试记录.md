## 2. 实测值（代码中对应常量）

### 2.1 遥控器档位（S.BUS 11 位原始值）

| 物理位置 | 原始值 | 对应常量 |
|---|---|---|
| 最上（UP） | **353**（0x161） | `RC_SW_UP_RAW` |
| 中间（MID） | **1024**（0x400） | `RC_SW_MID_RAW` |
| 最下（DOWN） | **1694**（0x69E） | `RC_SW_DOWN_RAW` |

SB 与 SC 取值相同。
判档逻辑：取离三个中心值最近的一个（`classifySwitch()`）。

### 2.2 摇杆中位（松手、手离开时）

| 通道 | 残留偏移 | 对应常量 |
|---|---|---|
| ch0（右摇杆左右） | **-40** | `RC_TRIM_CH0` |
| ch1 | 0 | `RC_TRIM_CH1` |
| ch2 | 0 | `RC_TRIM_CH2` |
| ch3（左摇杆左右） | **-8** | `RC_TRIM_CH3` |

不校准的表现：推前进时车会附带固定方向的平移（约 0.18 m/s 向左）。

### 2.3 速度上限

| 常量 | 值 | 含义 |
|---|---|---|
| `CHASSIS_MAX_LINEAR` | 3.0 | 满杆平移 m/s |
| `CHASSIS_MAX_ROT_RPM` | 40.0 | 满杆旋转 rpm |

| 摇杆 | 方向 | 行为 | 满杆 |
|---|---|---|---|
| 右摇杆 | 上 / 下 | 前进 / 后退 | 3.0 m/s |
| 右摇杆 | 左 / 右 | 左移 / 右移 | 3.0 m/s |
| 左摇杆 | 左 / 右 | 原地自转 | 40 rpm（顺时针为正） |
| 左摇杆 | 上 / 下 | **未使用** | — |

三个方向可以同时叠加（麦轮全向）：例如右摇杆推到右上角 = 斜向前进。

### 3.3 隐含规则

- 死区 ±0.02：摇杆在中位 2% 以内自动当作 0
- 掉线保护：100 ms 收不到遥控帧 → 自动停车
- 中位校准：已减去 ch0 = -40、ch3 = -8（见 2.2 节）
- 急停与掉线走同一条 `ChassisStop()` 路径

### 3.4 待上车确认

- **自转方向**：当前约定“左摇杆向右 = 车头向右转（顺时针）”。若实车相反，改 `ControlTask.cpp` 第三个参数符号，或改 `K*wz` 的符号
- **前进方向**：若推前进却后退，把 `WHEEL_DIR_*` 四个都取 `-1.0f`，不要改遥控器映射
- SB 中/下两档目前是空实现，是留给后续功能（慢速档、底盘锁定等）的入口
- `UserTask` 里的 M2006（ID5）未接入，目标恒为 0

## 5. 现象 → 原因对照

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 四个目标转速恒为 0 | SB 不在 UP 档 / SC 在下档 / 遥控器掉线 | 看 `sLeft`、`sRight`、`isOnline()` |
| `sLeft` 不随开关变化 | 档位原始值不对 | 重测第 2.1 节 |
| 前进时车往一边漂 | 摇杆中位未校准 | 重测第 2.2 节 |
| 电脑没有 COM 口 | 只插了 ST-Link，没插 C 板 USB | 用第二根 USB 线接 C 板 USB 口 |
| 接上电机后 CAN 无反应 | 之前无节点导致 bus-off | 断电重启 |
| 某个轮子不转 | 电调 ID 重复 / 接线 | 自检 + 检查 ID |
